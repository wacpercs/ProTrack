# ProTrack AI 🚀

> AI-ассистент для построения карьеры молодёжи 16–22 лет

## О проекте

ProTrack — это умный карьерный помощник, который анализирует твои интересы
и навыки, подбирает подходящие профессии, строит персональный план развития
и показывает актуальные вакансии с hh.ru.

## Возможности

- 🎯 Подбор топ-5 профессий на основе твоего профиля
- 🗺️ Персональная карьерная дорожная карта с этапами и курсами
- 💼 Актуальные вакансии через интеграцию с hh.ru API
- 🤖 AI-консультант по карьерным вопросам
